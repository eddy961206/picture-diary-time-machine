# 그림일기 타임머신

사진 한 장이나 일기 몇 줄을 넣으면 2010년대 초등학교 2학년 남자아이의 여름방학 숙제 같은 `그림일기` 이미지로 만들어주는 작은 웹앱이야.

## 들어있는 기능

- 참고 사진 업로드
- 날짜, 날씨, 제목, 장소, 일기 내용 입력
- 초딩 그림일기 감성 프롬프트 자동 생성
- OpenAI Image API로 이미지 생성
- 결과 이미지 다운로드
- API 키가 없어도 샘플 이미지와 프롬프트 미리보기 가능

## 실행 방법

Node.js 20 이상이 필요해.

```bash
cd picture-diary-time-machine
cp .env.example .env
```

`.env`에 키를 넣어줘.

```bash
OPENAI_API_KEY=sk-...
OPENAI_IMAGE_MODEL=gpt-image-2
PORT=8787
```

실행:

```bash
npm start
```

브라우저에서 열기:

```bash
http://localhost:8787
```

## API 방식

- 사진이 없으면 `/v1/images/generations`로 텍스트 기반 생성
- 사진이 있으면 `/v1/images/edits`로 참고 이미지를 넣고 새 그림일기 이미지 생성

## 배포할 때 주의할 점

- API 키는 절대 프론트엔드에 넣지 마.
- 지금 코드는 작은 MVP라서 로그인, 결제, 저장소, rate limit은 없어.
- 공개 서비스로 만들 거면 서버 쪽에 사용자별 요청 제한, 비용 한도, 업로드 이미지 삭제 정책을 꼭 넣어야 돼.
- 생성 이미지가 진짜 과거 숙제처럼 보일 수 있으니, 서비스 설명에 “AI 생성 이미지”라는 안내를 넣는 게 좋아.
